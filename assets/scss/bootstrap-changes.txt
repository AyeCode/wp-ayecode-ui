Changes to files that are not our own
=====================================

1-frameworks/ (Bootstrap) and components/ (the skin) are upstream code and are not edited.
Make changes in partials/, which load after the skin and override it.
The top-level files in this folder (_variables.scss, _root.scss, _utilities.scss ...) are ours.

Any change inside 1-frameworks/ or components/ needs approval first and is listed below
with the file, the change and the reason.


1-frameworks/
-------------
No changes.
